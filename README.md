# YMM4 音声スクラブプラグイン (YMM4AudioScrubPlugin)

ゆっくりMovieMaker4で、Premiere Pro のように
シークバーを動かしたとき・矢印キーでフレームを送ったときに、
その位置の音声を短く再生するプラグインです。

-----

## 主な機能・特徴

1.シーク時の音声スクラブ
タイムライン停止中にシークバーや矢印キーで位置を変えると、そのフレーム付近のミックス音声を再生します。プレビュー再生中は鳴らしません。

2.音声キャッシュ
タイムラインのミックス結果をメモリにキャッシュし、シークのたびに取り直さないようにしています。アイテムの追加・削除などがあればキャッシュを破棄して作り直します。

3.設定
YMM4 の設定（その他 → Audio Scrub）から有効/無効・音量・再生フレーム数を変更できます。

4.アップデート通知
YMM4 起動時に GitHub Releases を確認し、インストール中のバージョンより新しいリリースがあれば通知します。

## インストール方法


【.ymme形式】
このGithubリポジトリのReleaseから最新版の.ymmeファイルをダウンロードして実行すると自動的にインストールされます。

【手動】
このGithubリポジトリのReleaseから最新版のzipをダウンロードして解凍すると.dllファイルがあります。
.dllファイルをご自身のYMM4のフォルダ(ymm4/といいます)を開き、
ymm4/user/plugin/AudioScrub/(先程のdll)
と置きます。
AudioScrubフォルダは作成してください。
